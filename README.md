# 🎫 하이브리드 티켓팅 오토메이션 (Hybrid Ticketing Automation)

파이썬(Python)과 CustomTkinter GUI를 기반으로 제작된 **반자동(하이브리드) 티켓팅 보조 프로그램**입니다.

---

## ✨ 주요 기능

1. **하이브리드 제어 시스템 (F8 / F9 / F10 단축키)**
* **[F8]**: 설정된 다음 단계 목표 위치로 마우스를 부드럽게 이동합니다 (가감속 Easing 적용).
* **[F9]**: 해당 위치를 클릭하고 다음 단계로 넘어갑니다. 예매하기 진입 시 자연스러운 인공 딜레이와 함께 클릭 후 좌석 페이지를 자동 스캔합니다.
* **[F10]**: 최종 예매하기 버튼을 즉시 실행합니다.


2. **유연한 공연 시간 선택 및 공연 수 분기**
* **공연 시간**: 낮공연 / 밤공연 / 바로넘김(시간 선택 생략) 3가지 옵션 지원.
* **당일 공연 수**: 회차가 1개일 때와 2개일 때에 맞춰 예매하기 진입 좌표를 자동으로 분기하여 정확하게 진입.


3. **스마트 포도알(잔여석) 일괄 스캔 엔진**
* 좌석 페이지 진입 시 이미 예매된 회색/흰색 좌석을 실시간 RGB 픽셀 분석으로 완벽히 스킵합니다.
* 앞줄은 넓게, 뒷줄은 중앙 위주로 최적의 연석 후보를 자동 정렬하여 안내합니다.


4. **공식 서버 시간 동기화**
* 선택한 티켓 사이트의 공식 서버 헤더(Date)를 분석하여 밀리초 단위까지 정확한 서버 시계를 제공합니다.


5. **JSON 기반 외부 설정 관리**
* 사이트 정보, 공연장 프리셋, 좌표, RGB 값이 `ticketing_settings.json` 파일에 영구 저장되므로 언제든 쉽게 수정 및 백업이 가능합니다.

## 🚀 사용 방법 (Step-by-Step Guide)

### 1단계: 프로그램 실행

* 파이썬 스크립트를 실행하면 화면 우측 상단에 미니멀 화이트모드 제어 패널(880x440)이 나타납니다.
* 프로그램 창은 항상 위에 고정(`-topmost`)되어 있어 예매 창과 함께 쓰기 편리합니다.

### 2단계: 티켓팅 조건 설정 (`티켓팅 시작하기`)

메인 화면에서 [🎫 티켓팅 시작하기]를 눌러 제어 패널로 진입한 후 아래 항목을 세팅합니다:

1. **티켓 사이트**: 예매할 사이트 선택 (티켓링크, 예스24 등)
2. **공연장 프리셋**: 예매할 공연장 홀 선택 (예: 예스24아트원 1관, SH아트홀 등)
3. **관람 월**: `current` (이번달), `next` (다음달), `next_next` (다다음달) 중 선택
4. **날짜 (행, 열)**: 달력에서 예매할 날짜의 행(Row)과 열(Col) 번호 입력
5. **공연 시간**: `낮공연` / `밤공연` / `바로넘김` 중 선택
6. **당일 공연 수**: `1개 (기본)` 또는 `2개 (회차있음)` 선택
7. **[설정 적용]** 버튼 클릭

### 3단계: 실전 티켓팅 진행 (단축키 활용)

1. 예매 오픈 정각에 맞춰 제어 패널의 **서버 시계**를 주시합니다.
2. [F8]을 눌러 다음 단계(달력 넘기기 ➔ 날짜 선택 ➔ 시간 선택 ➔ 예매하기 진입)로 마우스를 차례대로 이동합니다.
3. [F9]를 눌러 해당 위치를 클릭합니다.
4. 좌석 선택 창이 열리면 프로그램이 자동으로 예매 가능한 포도알들을 스캔하여 첫 번째 포도알을 조준해 줍니다.
5. 계속 [F8] / [F9]를 눌러 원하는 좌석을 연달아 선택합니다.
6. [F10]을 눌러 최종 예매하기를 실행합니다.

## 🛠️ 추가 기능 (환경 설정 및 좌표 찾기)

* **좌표 및 RGB 찾기 (`CoordFinder`)**
* 메인 화면의 [🔍 좌표 및 RGB 찾기]를 누르면 마우스 커서가 위치한 곳의 실시간 화면 좌표(`X`, `Y`)와 픽셀 색상(`RGB`)을 정확하게 확인할 수 있습니다.
* **[Space]** 키를 누르면 현재 위치가 로그 박스에 영구 기록됩니다.


* **환경 설정 및 프리셋 관리 (`Settings`)**
* 각 티켓 사이트의 버튼 좌표(달력, 날짜, 낮/밤공연, 공연 1개/2개 예매하기 진입 등)와 공연장별 좌석 간격을 직관적으로 수정하고 `ticketing_settings.json`에 저장할 수 있습니다.
